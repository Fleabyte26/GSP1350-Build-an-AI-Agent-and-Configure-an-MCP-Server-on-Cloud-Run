# GSP1350 - Zoo tour guide agent: ADK + remote MCP server on Cloud Run

## Known lab traps/bugs (read first)

1. The model name is "filled in at lab start". If you copy the .env text from anywhere except your own lab page you get that literal phrase and the agent fails. You type it once in Setup below.
2. The region changes per lab instance. The MCP server URL contains the region, so a wrong region means the agent deploys fine but every zoo question fails.
3. The lab's PATH line is not needed here. Every command calls adk by its full path, ~/.local/bin/adk.
4. The deploy asks questions (continue? allow unauthenticated?). Answer Y to each. If you miss the unauthenticated one, the page opens as "Forbidden"; the block after the deploy repairs that.
5. Run the "update" block after the deploy before you click the check. The checker lags: wait 30-60 seconds and click again.
6. Do not run Task 6 (cleanup) until "Deploy the Agent" is green. Cleanup deletes what the checker looks for.

## Task 2. agent.py (5 pastes)

What you are building: a greeter agent saves the visitor's question to shared state, then hands off to a SequentialAgent that runs a researcher (MCP zoo tool + Wikipedia tool) and then a formatter. The MCP tool sends an ID token as a Bearer header, which is how Cloud Run service-to-service authentication works.

Paste 1 - imports and setup:

```bash
cd ~/zoo_guide_agent
cat > agent.py <<'EOF'
import os
import sys
import logging
import google.cloud.logging
from dotenv import load_dotenv

sys.path.append(os.path.dirname(os.path.abspath(__file__)))

from google.adk import Agent
from google.adk.agents import SequentialAgent
from google.adk.tools.mcp_tool.mcp_toolset import MCPToolset, StreamableHTTPConnectionParams
from google.adk.tools.tool_context import ToolContext
from google.adk.tools.langchain_tool import LangchainTool

from langchain_community.tools import WikipediaQueryRun
from langchain_community.utilities import WikipediaAPIWrapper

import google.auth
import google.auth.transport.requests
import google.oauth2.id_token

cloud_logging_client = google.cloud.logging.Client()
cloud_logging_client.setup_logging()

load_dotenv()

model_name = os.getenv("MODEL")

EOF
wc -l agent.py
```

You should see 28 agent.py

Paste 2 - the three tools:

```bash
cd ~/zoo_guide_agent
cat >> agent.py <<'EOF'
def add_prompt_to_state(
    tool_context: ToolContext, prompt: str
) -> dict[str, str]:
    """Saves the user's initial prompt to the state."""
    tool_context.state["PROMPT"] = prompt
    logging.info(f"[State updated] Added to PROMPT: {prompt}")
    return {"status": "success"}

mcp_server_url = os.getenv("MCP_SERVER_URL")
if not mcp_server_url:
    raise ValueError("The environment variable MCP_SERVER_URL is not set.")

def get_id_token():
    """Get an ID token to authenticate with the MCP server."""
    target_url = os.getenv("MCP_SERVER_URL")
    audience = target_url.split('/mcp/')[0]
    request = google.auth.transport.requests.Request()
    id_token = google.oauth2.id_token.fetch_id_token(request, audience)
    return id_token

mcp_tools = MCPToolset(
    connection_params=StreamableHTTPConnectionParams(
        url=mcp_server_url,
        headers={
            "Authorization": f"Bearer {get_id_token()}",
        },
    ),
)

wikipedia_tool = LangchainTool(
    tool=WikipediaQueryRun(api_wrapper=WikipediaAPIWrapper())
)

EOF
wc -l agent.py
```

You should see 61 agent.py

Paste 3 - the researcher agent:

```bash
cd ~/zoo_guide_agent
cat >> agent.py <<'EOF'
comprehensive_researcher = Agent(
    name="comprehensive_researcher",
    model=model_name,
    description="The primary researcher that can access both internal zoo data and external knowledge from Wikipedia.",
    instruction="""
    You are a helpful research assistant. Your goal is to fully answer the user's PROMPT.
    You have access to two tools:
    1. A tool for getting specific data about animals AT OUR ZOO (names, ages, locations).
    2. A tool for searching Wikipedia for general knowledge (facts, lifespan, diet, habitat).

    First, analyze the user's PROMPT.
    - If the prompt can be answered by only one tool, use that tool.
    - If the prompt is complex and requires information from both the zoo's database AND Wikipedia,
      you MUST use both tools to gather all necessary information.
    - Synthesize the results from the tool(s) you use into preliminary data outputs.

    PROMPT:
    {{ PROMPT }}
    """,
    tools=[
        mcp_tools,
        wikipedia_tool
    ],
    output_key="research_data"
)

EOF
wc -l agent.py
```

## Task 4. Deploy

Paste this alone and wait. It takes 5-10 minutes. Type Y and press Enter each time it asks a question.

```bash
cd ~/zoo_guide_agent
~/.local/bin/adk deploy cloud_run --project=`cat ~/project` --region=`cat ~/region` --service_name=zoo-tour-guide --with_ui .
```

You should see a final line with a Service URL ending in .run.app

Then paste this. It adds the label and environment variables the lab requires, makes sure the page is public, and prints the URL.

```bash
gcloud run services update zoo-tour-guide --region=`cat ~/region` --update-labels=dev-tutorial=codelab-adk --set-env-vars="MODEL=`cat ~/model`,MCP_SERVER_URL=https://zoo-mcp-server-`cat ~/projnum`.`cat ~/region`.run.app/mcp/,GOOGLE_CLOUD_LOCATION=global"
gcloud run services add-iam-policy-binding zoo-tour-guide --region=`cat ~/region` --member=allUsers --role=roles/run.invoker --quiet
gcloud run services describe zoo-tour-guide --region=`cat ~/region` --format="value(status.url)"
```

You should see the service URL on the last line.

Check my progress: Deploy the Agent (it can take a few minutes after a good deploy; wait and click again)

## Task 5. Test

Open the service URL in a new tab. In the ADK page, turn Token Streaming on (upper right), then send these one at a time:

```text
Hello
Where are the penguins located?
What is the average lifespan of a penguin in the wild?
What species are the penguins in our zoo, and what do they typically eat in the wild?
Where are the lions and what do they eat in the wild?
Do we have polar bears in this zoo?
```

What to watch: the first question uses only the MCP zoo tool, the second only Wikipedia, the third and fourth use both. Click the tool call bubbles to see which tool ran.

If zoo questions fail but Wikipedia ones work, the MCP URL is wrong: run cat ~/region and compare it with the region of zoo-mcp-server from Setup, fix ~/region, and paste the "update" block from Task 4 again.
